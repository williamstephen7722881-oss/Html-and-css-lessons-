HTML Lesson 1: Introduction to HTML

HTML stands for HyperText Markup Language. It is used to create the structure and content of a webpage.

Think of HTML as the skeleton of a house. It provides the basic structure.

HTML Lesson 2: Basic HTML Structure

<!DOCTYPE html>
<html>
<head>
  <title>My Website</title>
</head>
<body>
  <h1>Hello World</h1>
  <p>This is my first webpage.</p>
</body>
</html>

What Does Each Part Do?

  • <!DOCTYPE html> tells the browser that the document uses HTML5.
  • <html> is the main element that contains the webpage.
  • <head> contains information about the page.
  • <title> sets the text shown in the browser tab.
  • <body> contains the visible content of the webpage.

HTML Lesson 3: Common HTML Elements

Headings

<h1> to <h6> create headings.

Paragraphs

<p> creates a paragraph.

Links

<a> creates a clickable link.

Images

<img> displays an image.

Lists

<ul>, <ol> and <li> create lists.

Buttons

<button> creates a clickable button.

CSS Lesson 1: Introduction to CSS

CSS stands for Cascading Style Sheets. It controls the appearance of HTML elements, including colors, fonts, spacing and layout.

CSS Lesson 2: CSS Syntax

h1 {
  color: blue;
  font-size: 40px;
}
  • Selector: h1 chooses the element to style.
  • Property: color is what you want to change.
  • Value: blue is the chosen setting.

CSS Lesson 4: Styling a Simple Webpage

/* CSS */
body {
  background-color: #f5f7fb;
  font-family: Arial, sans-serif;
}

h1 {
  color: #2563eb;
  text-align: center;
}

p {
  font-size: 18px;
}

This CSS changes the page background, font, heading color, alignment and paragraph size.
