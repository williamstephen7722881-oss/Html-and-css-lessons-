The two languages every website is built from

HTML gives a page its structure. CSS gives it its look. Understand those two ideas well, and the rest of web design starts making sense fast.

<html-basics>

HTML: the structure

HTML (HyperText Markup Language) organizes content into elements — headings, paragraphs, images, links, lists — using tags. Tags usually come in pairs, wrapping the content they describe.

Browsers read this structure top to bottom and turn it into the page you see.

<article>
  <h2>My first post</h2>
  <p>Learning HTML step by step.</p>
  <a href="#">Read more</a>
</article>
.card {
  background: #ffffff;
  border-radius: 14px;
  padding: 24px;
  box-shadow: 0 8px 20px
    rgba(0,0,0,.08);
}
<css-basics>

CSS: the style

CSS (Cascading Style Sheets) controls color, spacing, fonts, and layout. You select an HTML element, then declare the properties you want it to have.

The "cascade" in the name means styles can come from multiple places, and clear rules decide which one wins.
